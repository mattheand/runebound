# M0/M1 Foundation Implementation Plan

> **For agentic workers:** Use the executing-plans skill to implement this plan task-by-task in this workspace.

**Goal:** Deliver a runnable Godot movement playground and reproducible physics tests.

**Architecture:** A reusable CharacterBody2D scene owns input and movement, with a Resource for tuning and a separate presentation node. A TileMapLayer playground supplies collision geometry and camera bounds; a main-menu scene launches it. Tests drive the actual input actions through engine physics frames.

**Tech Stack:** Godot 4.7 stable or newer verified stable Godot 4, typed GDScript, Compatibility renderer.

**Spec:** `specs.md`, M0 and M1; `docs/design/RUNEBOUND_Visual_References/ART_DIRECTION.md`.

## Global Constraints

- Logical resolution 640 × 360; nearest-neighbor filtering.
- Native Godot physics, named Input Map actions, configurable movement.
- Single-threaded web compatibility; no C# or GDExtensions.
- Original temporary art: blond hero, blue tunic, red cape; concept images remain reference-only.
- Verify actual movement, not just parsing. Stop scope at M1.
- Existing spec explicitly requests autonomous implementation rather than another design approval cycle.
